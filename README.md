# C++ Data Types Explorer

## Overview

This project is a simple C++ program designed to demonstrate the use of fundamental data types. It collects student information from the user, displays the entered details, and shows the memory size occupied by common C++ data types using the `sizeof()` operator.

---

## Concepts Covered

* `string` for storing text
* `int` for whole numbers
* `float` for decimal numbers
* `char` for single characters
* `bool` for true/false values
* User input using `cin`
* Output formatting using `cout`
* Memory size calculation using `sizeof()`

---

## Project Description

The program asks the user to enter:

* Name
* Age
* CGPA
* Grade
* Placement status

After collecting the data, it displays a formatted student profile. It then prints the memory size (in bytes) of several built-in C++ data types.
